# Foundrly iOS Baslangici

Bu klasor, Foundrly icin ilk SwiftUI mobil iskeletini icerir.

## Hazirlanan akıslar

- Giris yap
- Kayit ol
- Tab bar tabanli uygulama kabugu
- Ana Sayfa
- Kesfet
- Mesajlar
- Profilim
- Public uye profili
- Premium aktivasyonu
- Verified Talent basvurusu
- Backend'e bagli auth ve dashboard servisleri

## Xcode tarafinda sonraki adim

1. Xcode'da yeni bir `App` olustur.
2. Bu klasordeki Swift dosyalarini projeye ekle.
3. Minimum deployment target'i iOS 17 yap.
4. Simulatorde backend calisirken `localhost:8000` yerine gerekirse Mac IP adresini kullan.

## Not

Bu ilk turda amac, mobilin urun akisini baslatmak ve web/backend ile ayni bilgi mimarisini iOS tarafina tasimaktir. Sonraki turda:

- AI Team Builder
- admin tarafi degil ama founder aksiyonlari

eklenebilir.
